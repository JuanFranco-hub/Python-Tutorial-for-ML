## Sobre este curso

### ¿A quién está dirigido?

* **Principiantes:** Personas que nunca han programado y desean aprender desde cero.
* **Intermedios:** Quienes ya conocen algo de programación y quieren profundizar en Python para análisis de datos y machine learning.

Este curso está diseñado para **aprender practicando**, con ejercicios, ejemplos reales y proyectos que consolidarán tu aprendizaje.

---

Al completar este curso, estarás preparado para desarrollar proyectos en Python desde cero, aplicando tanto fundamentos como técnicas avanzadas.
